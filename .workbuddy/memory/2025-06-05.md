| 变量 | 值 | 用途 |
|------|-----|------|
| accent | #E11D48 | 主色/按钮/高亮 |
| bg | #000000 | 页面底色 |
| bg-card | #0C0C0D | 卡片背景 |
| bg-secondary | #09090B | 特性卡片背景 |
| border | #312E81 | 边框/分割线 |
| text-primary | #F8FAFC | 主文字 |
| text-secondary | #94A3B8 | 次要文字 |

| font-body | Inter | 正文（14-18px, 400-600）|
| font-mono | JetBrains Mono | 标签/数据（12-14px）|
